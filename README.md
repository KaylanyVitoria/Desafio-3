# 📍 Anuário do Ceará - Mapas

Projeto desenvolvido como desafio prático de Front-end, reproduzindo a página **Mapas** do Anuário do Ceará.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- jQuery
- Font Awesome

## 📱 Funcionalidades

- Layout responsivo para Desktop, Tablet e Mobile.
- Accordion desenvolvido com jQuery.
- Navegação semelhante ao layout original.
- Exibição dos mapas em formato JPG.
- Logo em formato SVG.

## 📂 Estrutura do projeto

```text
.
├── css/
│   └── style.css
├── images/

│   ├── mapa5.jpg
│   └── mapa6.jpg
├── script/
│   └── script.js
└── index.html
```

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/Desafio-3.git
```

2. Abra o projeto no Visual Studio Code.

3. Execute utilizando o **Live Server** ou abra o arquivo `index.html` no navegador.
